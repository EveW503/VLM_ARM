## 一、课题背景（含文献综述）

### 1.1 课题研究目的

近年来，以智慧农业为代表的农业现代化进程正在深刻改变传统种植与采摘模式。农业采摘机器人作为其中的核心装备，面临着在非结构化、高度动态的田间环境中实现自主作业的迫切需求。然而，目前主流的采摘机器人系统普遍采用传统目标检测 + 运动学逆解的架构范式，这一方案在受控实验室环境下表现尚可，但在真实农业场景中暴露出算法泛化能力差、缺乏语义常识等核心痛点。本课题旨在探索并构建一种视觉语言模型（VLM）高层认知 + 经典运动规划（ROS 2 + MoveIt 2）底层执行的混合分层具身智能架构，为复杂动态农业环境下的机械臂自主采摘提供一套可在仿真环境中完整验证的低成本技术方案，降低真实系统开发与迭代的试错成本。

### 1.2 国内、外研究现状和发展动态

随着农业采摘机器人向智能化、自主化的方向发展，在非结构化的复杂农业环境下机械臂的自主采摘与具身交互已成为智慧农业的前沿热点。在复杂的果园环境中，视觉感知与运动决策是决定抓取成功率的核心模块。研究表明，面对密集的枝叶遮挡、多变的光照以及多目标簇生，机器人不仅需要精确的几何三维坐标，更需要具备语义常识以制定如推挤防碰撞或按品质筛选的柔顺交互策略。

早期的采摘抓取研究主要依赖传统目标检测 + 经典运动规划的串联架构。这类方法具有概念简单、实时性强的优势，已经实现了工程落地并投入实际生产中。如刘旭赞等最新研制的垄作草莓采摘机器人，采用了YOLOv8-seg 实例分割结合 RRT 路径规划的典型框架，在温室无遮挡条件下的采收成功率达到了88.1%。然而，传统视觉算法基于封闭训练集训练，泛化能力弱，无法适应形态多变的采摘目标；此外，由于缺乏对目标物理属性的深层语义理解，此类系统无法区分刚性绝对障碍物与柔性可推挤障碍物。为了应对遮挡，传统方案往往需要外加物理吹风装置等硬件手段辅助[1]，当面对严重遮挡时成功率依然会大幅下降，导致底层规划器在面对复杂非结构化环境时频繁陷入无解状态。

为解决复杂环境下的交互难题，近期的研究开始探索端到端的具身智能大模型。如Brohan等人提出的RT-1与RT-2（VLA），通过海量真实机器人演示数据[2]，实现了从多模态输入到机械臂底层动作的直接映射。[3]这些端到端模型展示了极强的零样本泛化能力。然而，VLA模型对算力与数据集要求极高，且其决策过程具有不可解释性；在容错率极低的农业实操或仿真环境中，这种直接输出电机控制信号的方式极易引发物理碰撞风险，在短周期科研项目中难以实现低成本落地。

为了平衡大模型的泛化认知能力与物理运动的安全性，最新的研究趋势转向了大模型高层认知 + 传统算法底层执行的混合分层架构。如Ahn等人提出的SayCan框架[4]以及Driess等人开发的PaLM-E模型，成功将视觉语言模型（VLM）作为机器人的高层任务规划器[5]。VLM通过对输入图像进行常识推理，将复杂的自然语言指令自主拆解为一系列结构化的子任务，再交由传统的经典控制系统完成确定性的轨迹规划。这种架构既保留了VLM的语义理解优势，又保证了底层执行的安全性。

尽管现有混合架构在具身智能领域取得了显著进展，但在农业采摘的垂直场景下仍存在挑战：现有研究多集中于室内结构化桌面环境，针对农田复杂结构的深度语义推理策略尚不完善；且如何将VLM在二维空间输出的语义决策，低延迟、高鲁棒性地映射为三维物理空间中的连续采摘轨迹，缺乏针对性的验证。因此，探索低成本的VLM与传统运动控制融合范式，并在仿真环境中验证非结构化场景下的具身抓取成功率，成为本研究项目的重点。

## 二、研究方案介绍（主要内容）

### 2.1 研究内容

本课题旨在构建一个混合式分层架构的机械臂具身采摘系统，主要研究内容分为以下四部分：

1. 设计自上而下的认知-执行双层架构。明确各层级的系统边界，规范视觉语言模型与底层 ROS 2 运动规划节点之间的标准化的通信接口。

2. 研究在输入Gazebo中的 RGB图像及自然语言指令时如何通过提示词工程，使 VLM 输出包含目标二维坐标、障碍物语义标签、及建议排障动作类型的结构化 JSON 决策指令。

3. 针对 VLM 仅能输出二维像素指令的局限，研究二维语义到三维空间的映射算法。结合仿真环境中的深度图像与相机内参，利用 ROS 2 的 TF 坐标变换树，将二维像素锚点精准解算为机械臂基坐标系下的三维目标位姿。

4. 研究 MoveIt 2 如何接收上层映射后的三维目标点及排障策略约束，在带有软硬混合障碍物的 Gazebo 采摘场景中，执行基于障碍物分类的防碰撞路径规划与末端姿态控制测试。

### 2.2 创新点与项目特色

本课题创新点聚焦于VLM如何在非结构化农业场景中完成有效的语义决策，主要包含两项内容。

1. **障碍物语义辨识与主动排障策略**：传统运动规划将所有检测到的障碍物一视同仁，统一执行绕行策略，导致在枝叶茂密的果园场景中频繁规划失败。本课题通过精心设计的系统提示词，引导VLM对场景物体进行语义属性分类：对于树干、地面等绝对障碍物，输出绕行指令；对于软质枝叶、细藤等可形变障碍物，输出推移排障指令，随后在MoveIt 2层面设计相应的推扫轨迹。该机制打破了传统算法逢障必躲的局限，显著提升仿真场景中的任务完成率。

2. **基于自然语言的零样本目标选择与优先级排序**：系统支持用户以自然语言实时更新采摘策略，如"优先采摘暗红色的熟透果实"或"跳过有明显损伤的果实"。VLM结合当前图像，无需重训练即可完成符合描述的目标筛选，体现了大模型泛化能力强的核心优势。

### 2.3 技术路线、拟解决的问题及预期成果

#### 2.3.1 技术路线

- **感知层面**：通过深度相机获取农业场景的RGB-D图像，结合用户输入的自然语言指令构建多模态数据作为决策依据。
- **决策层面**：将多模态数据上送至商用 VLM API。依托大模型的常识推理能力，完成场景内的软硬材质辨识与目标筛选，并输出标准化的 JSON 决策数据。
- **映射层面**：通过解析 JSON 指令，并利用相机深度图提取像素点的深度值，结合相机内参矩阵与 TF 坐标变换树，将二维语义锚点解算为机械臂基坐标系下的三维空间目标位姿。
- **执行层面**：将映射后的 3D 目标位姿与 VLM 制定的排障约束条件传入 MoveIt 2 运动规划框架。利用其逆运动学求解器及避障算法生成连续平滑的关节空间轨迹，通过 ros2_control 接口驱动 Gazebo 中的机械臂模型，完成复杂环境下的安全采摘。

#### 2.3.2 拟解决的问题

- 非结构化农业环境下的软硬障碍物语义辨识问题
- 自然语言指令驱动的零样本采摘目标筛选问题
- 二维视觉坐标向三维空间安全抓取轨迹的映射问题

#### 2.3.3 预期成果

- 完成基于 VLM 与 ROS 2 + MoveIt 2 融合的机械臂具身抓取仿真平台构建，实现复杂场景下的自主语义认知与抓取功能
- 技术指标包括：自然语言采摘指令意图解析正确率≥90%，软质障碍物场景下的轨迹规划成功率≥85%，仿真环境下的综合抓取成功率≥80%
- 项目总结报告1份，及核心场景仿真演示视频1套
