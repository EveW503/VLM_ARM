设计概览：PyKDL 替代 MoveIt

仅改造 grab_action_simple.py，vlm_bridge/camera_utils/prompts 不受影响

Before (MoveIt)
依赖:
├── moveit_msgs (MoveGroup, PlanningScene,
│               CartesianPath, Constraints...)
├── PlanningSceneManager
│   └── /collision_object (topic)
│   └── /attached_collision_object (topic)
├── /move_action (MoveGroup action)
├── /compute_cartesian_path (service)
└── /arm_controller (trajectory exec)

流程:
PRE_GRASP → MoveGroup(IK+plan)→执行
APPROACH  → GetCartesianPath→执行
LIFT      → MoveGroup(IK+plan)→执行
TRANSPORT → MoveGroup(IK+plan)→执行
After (PyKDL)
依赖:
├── PyKDL (Python KDL bindings)
├── urdf_parser_py (parse URDF → KDL chain)
├── sensor_msgs/JointState (IK seed)
├── tf2_ros (orientation query)
└── /arm_controller (trajectory exec)

流程:
PRE_GRASP → IK(joint_interp)→执行
APPROACH  → IK(cart_interp)→执行
LIFT      → IK(joint_interp)→执行
TRANSPORT → IK(joint_interp)→执行

模块拆分

🆕 ik_manager.py (新文件)

  • IKManager.__init__: 从 /robot_description 加载 URDF → KDL Chain → KDL Solver
  • solve_ik(pose, seed): 单次 IK 求解，返回关节角或 None
  • joint_interpolate(start, target, max_step): 关节空间线性插值 → JointTrajectory
  • cartesian_interpolate(start_pose, target_pose, current_joints, max_step): 笛卡尔插值 → 逐点 IK → JointTrajectory

✏️ grab_action_simple.py (改造)

  • 砍掉: MoveGroup action, CartesianPath service, PlanningSceneManager, moveit_msgs 全部
  • 砍掉: _build_request, _send_move_request, _move_*_cb
  • 新增: IKManager 实例, /joint_states 订阅 (IK seed)
  • 改造: PRE_GRASP/LIFT/TRANSPORT → IK + joint_interp + execute
  • 改造: APPROACH/PUSH_SWEEP → cartesian_interp + execute
  • 砍掉: 所有 _psm.xxx 调用, _target_object_registered

状态流保持不变

IDLE → SETUP → PRE_GRASP → [PUSH_SWEEP] → APPROACH → GRASP
  → LIFT_PLAN → TRANSPORT_PLAN → PLACE → IDLE

状态机逻辑不变，只换底层运动执行方式。
